# Baseball_Gambling_Game

# Inspiration
For me, when my partner brought up the idea of predicting baseball calls (as a sport), I felt inspired because I know quite a lot about baseball. In fact, I feel very passionate about it. This is intended to create a new form of entertainment for sports betters.

# What it does
Challenges a user to guess what the call by the umpire is.

# How we built it
We utilized mostly frontend aspects of the project using only HTML and javascript.

# Challenges we ran into
We had significant difficulty with building the backend part of the project since that was what I was use to doing with previous projects. The reason being was because I was already working off of a preset backend that already had a localhost set up. I did not have any experience knowing how to manually set up both a database and a new localhost server.

# Accomplishments that we're proud of
Fixing bugs such as what shows up on the application interface, the video playing correctly, and certain buttons being shown when clicked.

# What we learned
Simple is better than complex as well as work smarter not harder and more complex.
